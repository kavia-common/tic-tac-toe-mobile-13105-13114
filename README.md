# tic-tac-toe-mobile-13105-13114

**Note:**  
This project uses Expo for React Native development and does not include native Android/iOS build files (`android/`, `ios/`, or `gradlew`).

- If you see `bash: ./gradlew: No such file or directory`, it is expected unless you run `expo prebuild` or eject the app for native builds.
- No further gradle or native project steps are required for standard Expo workflows.
